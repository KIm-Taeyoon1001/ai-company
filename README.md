# ai-company

방향 재설정 중. 저장소를 비웠다.

## 이전 시도

AI 에이전트가 릴레이하며 정적 글을 생산하는 파이프라인을 만들었고, 실제로 작동했다.
글 3편을 발행했고 검수 에이전트가 지어낸 수치와 존재하지 않는 출처(404)를 실제로 잡아냈다.

접은 이유는 기계가 아니라 만드는 물건이었다. LLM이 2차 자료를 요약한 정적 글은
지금 인터넷에서 가장 흔한 물건이고, 검색에서 원문을 이길 방법이 없다.

전체 코드와 결과물은 `archive/content-experiment` 태그에 있다.

```bash
git checkout archive/content-experiment
```

## 그때 알아낸 것 (다시 만들 때 참고)

- **무료 LLM의 진짜 병목은 분당이 아니라 모델별 일일 토큰 한도다.** Groq 는 모델당 20만.
  기다려도 안 풀린다. 같은 키의 다른 모델로 갈아타야 한다
- **응답 헤더에 실제 잔량이 실려 온다.** 추정하지 말고 그걸 읽어라
- **에이전트에게 "이미 읽었다"고 알려주는 것으로는 안 멈춘다.** 본문을 안 줘야 멈춘다
- **결과물은 승인 게이트를 거쳐야 한다.** 안 그러면 검수가 반려한 글도 이미 발행돼 있다
- **반려할 때마다 새 작업이 생기면 재시도 한도가 안 걸린다.** 왕복 횟수를 따로 세야 한다
- **조회 실패를 0으로 그리지 마라.** 관제 화면이 장애를 정상으로 보여주는 게 최악이다
